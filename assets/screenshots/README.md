# 📸 Thư viện Hình ảnh & Ảnh chụp Màn hình (Screenshots)

Thư mục này dùng để lưu trữ các hình ảnh chụp màn hình (screenshots), sơ đồ kiến trúc (diagrams) hoặc ảnh động GIF để hiển thị trực tiếp trên file [README.md](../../README.md) của dự án trên GitHub.

## 📂 Danh sách hình ảnh đề xuất:

| Tên file | Mục đích hiển thị trong README |
| :--- | :--- |
| `client-homepage.png` | Giao diện trang chủ và tìm kiếm bất động sản |
| `ai-rag-chat.png` | Giao diện trợ lý ảo AI tư vấn BĐS (Spring AI RAG Chat) |
| `admin-dashboard.png` | Tổng quan Dashboard quản trị viên (Doanh thu, số lượng tin) |
| `admin-system-health.png` | Bảng điều khiển sức khỏe hệ thống (JVM, HikariCP, HTTP metrics) |
| `grafana-dashboard.png` | Dashboard giám sát thời gian thực Prometheus & Grafana |

> 💡 **Cách dùng:** Bạn chỉ cần chụp ảnh màn hình giao diện web, đặt tên file theo danh sách trên và lưu vào thư mục `assets/screenshots/` này. File README.md ở thư mục gốc sẽ tự động hiển thị ảnh khi xem trên GitHub.
